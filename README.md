# TscanPlus-Keygen
学习型逆向项目，实现了 TscanPlus 的离线认证注册机，各个版本应该都行，实测 **v3.5.2**。

一个 Go + Wails 写的程序。

先 dump 前端，顺着 JS 找到三个关键 native 函数入口，然后进 IDA 跟 Go 部分。后面是各种混淆：大量没什么实际意义的计算、各种 selector / rotate / S-Box / mod 257，只为了把数据流搅乱。

一共有三套 AES 相关逻辑，实际上只用了两套。剩下一套做得很复杂，真的会被调用，key 也能完整算出来，但最后必然走 fallback，结果根本不会用，纯诱饵。

真正的两套 key / IV 被拆散藏在 **Go、cgo 和 asm** 里，每个地方拿一点，最后再拼起来。注册机脚本基本就是把这些变换全部逆着实现了一遍。

说实话，这种设计在密码学上基本没有任何防御意义。数据最终还是要在本地被还原和使用，不会凭空增加安全性，主要作用就是增加逆向人员的阅读成本。

只能说很有 CTF 选手的风格：花里胡哨，意义不明。作为 CTF 题目可以，但从工程或者密码学角度看，确实挺无聊的。

实际上，如果只是想做注册机，用动态分析其实很简单。把关键函数关系理清楚以后，打两个断点就能直接拿到需要的数据。

只是既然是拿来学习的，最后还是选择把整套静态逻辑跟明白了。
